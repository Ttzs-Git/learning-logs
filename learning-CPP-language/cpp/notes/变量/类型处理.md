## 类型别名(type alias)

### 目的

**类型别名** 使复杂的类型名字变得简单明了、易于理解和使用

### 传统范式: 

```cpp
typedef <type> <name>;// <name> 是<type>的别名
typedef <type> *<name_2>;//<name_2> 是<type>*的别名
```

**注意** const <指针别名> = 指向Type的常量指针;简单替换去理解是错误的,需要关注基本数据类型的改变

### 别名声明(C++11 新特性)

> C++11 新特性

#### 范式

```cpp
using <name>=<type>; //规定左侧的名字成右侧类型的别名
```



## auto类型说明符 (c++11)
> C++11新特性

### 范式

```cpp
auto <name>=<sth>;//由于auto根据初始值推断类型，必须有初始值
```

- 编译器推断出来的auto类型有时候和初始值的类型并不完全一样，编译器会适当地改变结果类型使其更符合**初始化规则**
- 复制一个引用的时候会使用**被引用对象的类型**

- 保留底层const,一般忽略顶层const

- 希望保留顶层const需要使用:const auto 声明符列表 = 内容;

- 设置一个auto的引用,初始值中的顶层常量属性依然保留;但是,不适用auto时,给一个初始值绑定一个引用,此时的常量就不是顶层常量

## decltype类型指示符(c++11)

### 目的

希望从表达式的类型推断出要定义的变量的类型，但是不想用该表达式的值初始化变量

### 范式

```cpp
decltype(<value|expression>) <name>;
```

- decltype(**变量**) **返回全部类型** --->包括顶层const和引用

- 如果想要得到引用的对象的类型,需要进行**初始化**;

- decltype(**expression**)**返回表达式结果对应的类型** 
- 如果表达式的结果对象能作为一条**赋值语句的左值**，将返回**引用**

- decltype ((变量))---表达式;变量将被认为是一种可以作为赋值语句左值的特殊表达式

- decltype获得引用的情况:1.((变量));2.*指针;3.引用
