## 介绍

### 定义与作用

**const** 是关键字，用于指示变量的值不可修改

### 用法

```cpp
const <type> <name> = <val|字面值常量>;
<type> const <name> = <sth>;//这种用法比较少见

```

**注意** const属性的变量**必须初始化**

### 编译器和const

- const修饰的变量在编译时会被视为**只读**，尝试修改将导致编译错误
- 编译器可能将其储存在只读内存区域
- 编译器会将所有用到该变量的地方都替换成对应的值——**const值替换**

### 文件和cons
- 默认状态时,const 对象**仅在文件内有效**;

- 多文件共享,头文件的声明处加上**extern**

## 常量引用(const的引用,reference to const)

**注意**: 常量引用不能被用作修改它所绑定的对象

```cpp
const <type>& <name> = <val>; //该<val>可以是常量也可以是非常量，字面量，表达式计算的值
```

### 注意

**常量引用可以绑定类型不一致的对象**

原因: 

**临时量(temporary)对象**——当编译器需要一个空间来暂存表达式的求值结果时临时创建的一个未命名的对象

将表达式绑定在**const属性的临时量对象**

## 指针和const

### 指向常量的指针

```cpp
const <type>* <name>=<val>;// 将变量绑定在常量，非常量
```

**注意** 

1. 要想存放常量对象的地址，只能使用指向常量的指针
2. **指针的类型必须与其所指对象的类型一致**，但是允许令一个指向常量的指针指向一个非常量对象

### 常量指针(const 指针)

```cpp
<type>* const <name>=<val>;
```

**注意**

1. 常量指针**必须初始化**

### 顶层const和底层const

**顶层const**: 表示**实体本身是常量**

**底层const**: 表示**指针或引用所指向的数据是常量**，不能通过该指针或引用来修改这些数据

### 拷贝操作:

顶层const不受影响;

底层const的限制不能忽视,拷贝对象双方必须拥有相同的底层const资格(或者两个对象的数据类型必须能够转换)

**类型转换**:非常量转化为常量



### 常量表达式

**常量表达式** 值不会改变并且在编译过程中就能得到计算结果的表达式

**属于的元素** 字面值 ; 用常量表达式初始化的const对象

**判定原则** 数据类型和初始值共同决定

#### constexpr类型(C++11 新特性)

> C++ 11 新特性

**意义**  允许将变量声明为`constexpr`类型以便由编译器来验证变量的值是否是一个常量表达式

**要求** 声明为`constexpr`的变量一定是一个常量，而且必须用常量表达式初始化

##### 范式

```cpp
constexpr <type> <name>=<constexpr>;
```

##### constexpr函数(C++11新特性 C++17新特性)

```cpp
inline constexpr <return_type> <func_name>()
{
    return <n>;
}
```

> C++17 constexpr函数自动隐式内联

**注意** 这种函数应该足够简单以使得编译时就可以计算其结果

**inline**关键字允许在多个翻译单元中定义同一个函数，而不会引起链接错误

**解释** 由于在头文件中定义函数，而非声明所以必须使用inline

##### constexpr指针

```cpp
constexpr <type> *<name>=<sth>;//constexpr限定符仅对指针有效
```

**constexpr指针指向的对象**: 

- nullptr或者0
- 存储于某个固定地址中的对象(定义于所有函数之外的对象)

##### 字面值类型

算术类型,引用和指针都属于字面值类型;其中指针必须是nullptr或0,或者存储于某个固定地址中的对象

constexpr指针只能指向所有函数体之外的对象(地址固定不变)和staic修饰的变量

constexpr声明中如果定义了一个指针,限定符仅对指针有效,和指向的对象无关

自定义类,IO库,string等不属于字面值类型
