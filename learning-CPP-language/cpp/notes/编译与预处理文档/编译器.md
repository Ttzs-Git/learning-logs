# 编译器

## 编译理论

**临时量机制**: 编译器需要一个空间暂时存储表达式的求职结果时临时创建的一个未命名的对象

**编译器拓展**: 支持非标准的特性

## 编译指令

### 注意

1. 不需要指定头文件,编译器会自动查找
2. 如果头文件是非标准路径(即不在编译器的默认搜索路径中),可能需要使用`-I` 选项来指定额外的头文件搜索路径

### 编译文件

```bash
g++ <file>.cpp -o <filename>
```

**注意**:

1. 不适用**-o**指令导致生成默认文件**a.out**的可执行文件

```bash
g++ -I<folder> <file>.cpp -o <filename>
```

**注意**

1. **-I**后面直接跟着的是目录名

2. 如果你的项目包含多个源文件（`.cpp` 文件）和/或多个头文件，并且它们位于不同的目录中，

   你可能还需要使用 `-L` 选项来指定库文件的搜索路径（如果你链接了外部库的话），以及使用 `-l` 选项来指定要链接的库名（去掉前缀 `lib` 和后缀 `.so` 或 `.a`）
