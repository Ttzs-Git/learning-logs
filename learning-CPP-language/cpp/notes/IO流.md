## 输出流

### 前提条件

```cpp
#include <iostream>
```



### 基本结构1

```cpp
std::cout << <sth>;
```

 **注释**: 

- **std::cout** 是标准库中的一个对象，代表输出设备，通常是屏幕。

- 可输出的内容: 字符串，浮点数，字符，布尔值(一般将布尔值转换为整数1，0)

- << 就是**插入运算符** **输出运算符**

### 直接输出布尔值(新特性C++11)

> **新特性: C++11** 

```cpp
std::cout << std::boolalpha;
std::cout << <bool_value> ;
```



###  操纵符

- **std::endl** 用于在输出后插入换行符，并刷新输出缓冲区，确保立即在屏幕上显示输出

- **std::boolalpha** : 用于控制布尔值的输出格式 (C++ 11)

`std::iomanip` 头文件中定义的操纵符（如 `std::setw` 和 `std::setprecision`或使用C++20引入的新特性（如格式化库 `std::format`，尽管这不是通过 `std::cout` 直接使用的，而是用于生成格式化字符串）
