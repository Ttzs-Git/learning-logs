## 指针入门

### 定义

**指针的定义** 特殊的变量，存储另一个变量的内存地址

**特性** 能通过指针直接访问和操作内存中的数据

**说明**

1. 指针值的可能取值:指向一个对象;指向紧邻对象所占空间的下一个空间;空指针,意味着指针没有指向任何对象;无效指针(野指针)

### 声明范式

```cpp
<type> *<val>;
```

### 初始化范式

```cpp
<type> *<val>=&<val_2>;
```

**注意**

1. **不能定义指向引用的指针**

2. 除了两个例外,指针的类型都要和它所指向的**对象严格匹配**

### 解引用范式

```cpp
*<pointer>;
```

**注意**  解引用操作**适用于指向某个对象的有效对象**

### 空指针(增加C++11新特性)

```cpp
<pointer>=nullptr;//C++ 新特性
<pointer>=0;
#include<cstdlib>
<pointer>=NULL;
```

**不能将值为0的变量赋给指针**



### 万能指针

**万能指针(void*)**(存放任意对象的地址;但不清楚时什么类型的对象)

#### 操作

1. 比较;
2. 作为函数的输入输出;
3. 赋给另一个void*指针;

#### 禁止

1. 不能对void\* 直接解引用
2. 不能直接操作void\*指针所指的对象

### 指向指针的指针(二级指针..)

```cpp
<type> **<pointer_2_class>=&<pointer_1_class>;
```

### 指向指针的引用

```cpp
<type>* &<refer>=<pointer>;
```

**注意**

1. 不存在指向引用的指针

2. 从右向左阅读,离变量名最近的符号对变量的类型由最直接的影响

### 指向常量的指针

```cpp
const <type> *<pointer>=&<val>;
```
**注意**

1. const 修饰的变量只能由const修饰的指针指向

2. const 修饰的指针可以指向任意非const修饰的变量,无法通过指针修改值,但是可以通过其他方式

### const 指针

```cpp
<type> * const <pointer>=&<val>;
const <type> * <pointer>=&<val>;//指向常量的常量指针
constexpr const <type> * <pointer>=&<val>; //指向常量的常量指针 
```



### 顶层const和底层const

**顶层const**:指针本身是个常量;

**底层const**:指针所指向的对象是个常量;

> 容易混淆的是 const+非指针类型 和 const+指针类型

### 常见指针操作

1. 给指针复制;
1. 逻辑判断(指针合法性判断;指针相等);

**指针相等的情况**:1. 空指针;2. 指向同一个对象;3. 指向了同一个对象的下一个地址;4. 有时,一个指针指向一个对象,另一个指向另外对象的下一个地址
