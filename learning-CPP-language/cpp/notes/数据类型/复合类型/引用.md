## 左值引用

### 定义

**引用** (左值引用;引用将它和它的初始值对象绑定在一起)

**优势** 更安全 更简洁

**左值引用的特点** 具有持久状态的对象 明确的内存地址 可以被多次赋值

**理解** 引用**不是对象**，是**变量的别名**(地址一致)，无法定义引用的引用

**特性**

1. **必须初始化**
2. **一旦绑定，不可修改(绑定的对象)**(对象的内容可以修改，但是只能是这个对象)
3. **没有空引用**
4. 引用的类型要和与之绑定的对象严格匹配
5. 除了两个例外,引用只能**绑定在对象**上,而不能与字面值或某个表达式的计算结果绑定在一起

**实现方式** 引用在内部使用指针实现

### 范式

```cpp
<Type> &变量名=xxx;//声明必须初始化
```

## 常量引用(对const的引用)

##### 范式

``` cpp
const <type> &<标识符> = <任意变量|字面值常量>
```

> 非const的引用 无法引用 const类型的变量

> const的引用时允许用任意表达式作为初始值,只要该表达式的结果能转化成引用的类型(临时量机制)

> 非const的引用 是对变量的直接引用;const的引用的是临时量

## 右值引用(C++11新特性)

> C++ 11 新特性

### 定义

**右值引用的特点** 临时的、没有持久状态的值 没有内存地址 其内存地址在表达式结束后就变得无效

**目的** 为右值(即临时对象或即将被销毁的对象)创建一个引用，作为函数参数（实现移动语义）和返回值（允许链式调用等）

**支持移动语义(move semantics)** 允许我们在对象被销毁前“窃取”其资源（如动态分配的内存、文件句柄等），而不是进行深拷贝

### 使用范式
```cpp
<type>&& <val_name>=<字面值常量|函数>;
```
