## 类基础用法

### 类的定义

`类的组成`:`说明部分`和`实现部分`

```cpp
class <class_name>
{
    private:
    <content>;
    protected:
    <content>;
    public:
    <contenet>;
};
```

**注意**

1. 类的头部没有冒号,这一点跟Python不同
2. 类的尾部要将上**分号**
3. 默认属性是`private`
4. `访问权限修饰符`(访问控制修饰符):`private`  `public`  `protected`
5. 定义类的时候，系统不会分配`存储空间`

### 访问属性

`public`:类为外部提供访问的接口,定义类的公有成员,可以被程序中任何代码访问

`private`:私有成员，仅能被类的成员函数和友元访问

`protected`:受保护成员，仅能被类的成员函数、友元和派生类访问

> 还是有其他的机制实现外部访问`private` `protected`

### 对象的定义

```cpp
<Class> <oject_name>;
```
**注意** 定义对象时,系统分配存储空间

### 访问类的数据成员

```cpp
<object_name>.member;
```

```cpp
<object_pointer>->member;
```

## 成员变量与成员函数

### 成员变量

- **成员变量（Member Variables）**：用于存储对象的状态信息。
- **命名约定**：常用下划线结尾（例如 `name_`）表示成员变量，避免与局部变量混淆

### 成员函数

- **成员函数（Member Functions）**：定义对象的行为，可以访问和修改成员变量。

- **常成员函数（Const Member Functions）**：保证函数不会修改对象的状态。

- **设计模式**

	- 1. 以数据为中心，分析类的内部数据结构，根据类的数据特征分析得出可以提供的服务和接口
	- 2. 以行为为中心，首先关注类应该提供的接口和服务，再根据此，寻找支撑服务的相关静态特征

#### 成员函数的实现

```cpp
...
    public:
	<return_value> <function_name>(<argument_list+default_value>)
	{
    	<body>
	}
```

```cpp
<class_name>::<function_name>()
{
    <body>
}
```

**注意**

1. 通常,将函数定义为`public`，数据定义为`private`
2. 成员函数由权访问本类对象的所有成员
3. 所有的对象公用一套成员函数
4. 成员函数的实现可以在类中,也可以在外部。推荐:小型的使用第一种,大型的使用第二种

### 常成员函数

```cpp
...
    public:
	<return_val_type> <func_name>(<argument_list+default_value>) const;
```

```cpp
<class_name>::<function_name>() const
{
    <body>
}
```



### 内联函数

`定义`:编译器在编译代码时，设法以内联函数的函数体代替函数调用,加速代码运行

`实现`:在类中，定义函数或者使用`inline`关键字

## 构造函数与析构函数

###  构造函数

- **默认构造函数**：没有参数的构造函数。

- **参数化构造函数**：接受参数以初始化对象。

- **拷贝构造函数**：用一个对象初始化另一个对象。

- **移动构造函数（C++11）**：从临时对象“移动”资源。

**特性** 初始化列表

### 析构函数

- **析构函数（Destructor）**：在对象生命周期结束时调用，用于释放资源。

### 构造函数的实现

#### 初始化列表

```cpp
<Function header>:<var>(value)..
{}
```

**注意** `初始化列表`:列表和形参列表之间以`:`分隔，变量之间使用`,`分隔

#### 系统默认构造函数

```cpp
<class_name>::<class_name(function_name)>()
{}
```

**注意**

1. `系统默认构造函数`无参数,只分配内存空间，不进行初始化;只在系统不存在构造函数的时候，被**自动调用**

#### 默认构造函数

```cpp
<class_name>::<class_name>():<val_>=<val>
{}
```

#### 参数化构造函数

```cpp
<class_name>::<class_name(function_name)>(<arguments_list>)
{
    <body>
}
```

**注意**

1. 构造函数一定是以`类名命名`的函数，反之，成立
2. 构造函数没有`返回值类型`
3. 构造函数的作用:`分配内存空间`或者`设置初始值`
4. 构造函数只在创建对象时由`系统自动调用`，且禁止出现`对象名.构造函数(参数列表)`
5. 如果已经存在任何样式的构造函数，编译器不再提供默认构造函数

```cpp
...
    <class_name> <object1>=<constructor>(<arguments>)
    <object1>=<constructor><arguments>
```

**注意** 第二个是使用构造函数创建无名变量，并且赋值给<object1>

```cpp
...
    <class_name(function_name)>(<arguments_list>)
```

类中，声明的构造函数参数列表中参数提供默认值；

**建议构造函数都提供默认的参数值**

#### 拷贝构造函数

```cpp
<Function header>(const <class_name>& <object_var>)
{
    <body>
}
```

**注意** 使用**对象的引用**作为构造函数的输入

**思考** 新的对象为什么可以访问输入对象的私有成员？ 同类之下的对象类似友元的关系

#### 移动构造函数(C++11 新特性)

```cpp
<Function header>(<class_name>&& <n>)noexcept:
<val_>(std::move(n.<attribute>)) 
{
    
}
```

**注意** 

1. 被移动的数据不可再次使用
2. 属于类的数据不可yi'dong


### 析构函数的实现

```cpp
<class_name>::~<class_name(functio_name)>():
{
    <body>
}
```

> `注意点`：
>
> 1. 析构函数一个类`只有一个`，且命名只能是`~<class_name>`
> 2. 析构函数`无返回值`和`重载`
> 3. `调用情况`:对象生命周期的结束,new创建的对象使用delete释放时
> 4. 系统可以提供默认的析构函数，但是当使用动态内存的时候，建议定义
> 5. **析构函数的调用一定与构造函数的调用顺序相反**

## 深复制和浅复制

1. `浅赋值`:只将两个同类对象的成员**逐个赋值**，可能出现**指针悬挂** 的问题
2. `深复制`:使用特殊的拷贝构造函数


```cpp

```

```cpp
*<arr+i>.member
```

### 对象指针

```cpp
<class> *<pointer>;
```

```cpp

```

## this 指针

`this指针`:指向对象的特殊指针，无法修改

类中函数使用对象的内容时，可以省略`this指针`

## 内存空间

1. 内存空间的分配是从**高地址**开始
2. 同一个对象的各数据成员,新定义成员占低字节，后定义成员占高字节(不同计算机配置不同)
