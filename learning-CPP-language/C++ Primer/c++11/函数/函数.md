## 函数概论
- 定义函数
```cpp
<return_type> <func_name>([arg_list])
{
	<statemnent>
}
```
- 调用函数
> 通过**调用运算符** 执行函数
```cpp
<func_name>([arg_lists])
```
> 1. 实参初始化函数对应的形参
> 2. 将控制权转移给**被调用函数**

- return语句的作用
> 1. 返回return语句中的值
> 2. 将控制权从被调函数转移回**主调函数**
- 形参和实参
> 形参必须和实参类型能转换，数量相等
- 形参列表
> 形参列表可以是< >或者<\void>来表示空形参

- 局部对象
1. 生命周期(lifetime): 对象的生命周期是程序执行过程中该对象存在的一段时间
2. 作用域: 名字的作用域是程序文本的一部分，名字在其中可见
> 常见对象: 自动对象，局部静态对象
- 函数声明(函数原型)
- 分离式编译
## 参数传递
### 传值调用(值传递)
- 传递普通对象
- 传递指针对象
### 引用调用(传引用调用)
> 引用的优点: 支持无法拷贝的对象的间接调用
> 对于char，直接传递是更为高效的
#### const形参和实参
实参初始化时忽略顶层const
> 重载函数中，有没有顶层const是一样的
- const下指针和引用的实参和形参的关系
1. 普通指针指向普通对象，无法指向常量对象
2. 普通引用引用普通对象，无法引用常量对象和字面值常量和无法转换的类型
3. 底层const指针可以指向普通对象，
4. const引用可以引用普通对象和字面值
5. 底层const无法给普通指针赋值
6. 常量指针无法给普通指针赋值
7. 普通指针无法引用字面值常量
8. 顶层const对象可以赋值给非顶层const对象
- 数组形参
1. 数组的两大特性: 不允许拷贝；数组名有时会转化成指针
2. 数组必须考虑是否越界访问
- 管理指针形参
1. 拥有标记的数组，如:C风格字符串
2. 传入首指针和尾指针
3. 显式传入一个表示数组大小的形参
- 数组的引用
```cpp
<type> <func>(<type> (&<arr>)[<n>])
```
> 该函数只能使用大小为n的数组

- main函数
```cpp
int main(int argc,char* argv[])
```
```cpp
int main(int argc,char** argv)
```
> argv[\0]保存程序的名字
> 最后一个指针之后的元素为0‘
》 argv都是C风格字符串

## 编写建议
1. 建议函数声明和变量声明在头文件中
2. 建议使用引用传值，且如果无需改变引用形参的值，最好声明为常量引用
