# math 模块

```python
import math
```

## 常用数值

```python
math.e
```

> **含义**: 自然对数

```python
math.pi
```

> **含义**： 圆周率

## 常用函数

```python
math.factorial(<n>)
```

> **目的**： 实现阶乘——n！

```python
math.sin(<n>)
```

> **目的**： 计算正弦值

```python
math.log(<n>)
```

> **目的**: 计算n的自然对数值

```python
math.gcd(<n1>,<n2>)
```

> **目的**： 计算两个整数的最大公分母(python>=3.5)
