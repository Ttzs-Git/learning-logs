# 范围(range)

- 1. 创建范围

  ```python
  range(start,end.step)
  ```

  > 表示`整数范围`
  >
  > `参数`:
  >
  > 1. `start`:
  > 2. `end`
  > 3. `step`:

  > - range()函数可以实现省略第一个和最后一个参数,是否违背函数的默认值参数的设计原则?
  > - 内置函数,参数解析逻辑由解释器底层实现.同时,参数数量决定定义,绕过了普通函数调用机制

- 2. 转化为`list`

  ```python
  list(<range对象>)
  ```

  > 将`range对象`转化为`list对象`
