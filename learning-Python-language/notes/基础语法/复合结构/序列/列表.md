# 列表——可变类型

## 基本内容

- 列表字面量(list literal)

> `计算结果`:一个`list`实例,以及一个计算结果为列表中元素值的元素选择表达式

## 创建列表

- 1. []直接创建

- 2. list()函数组装

```python
list(range(start,end,step))
```

> 生成`数值列表`

```python
list('str')
```

> 生成`字符列表`

- 3. 列表推导式(指令:`LIST_APPEND`指令)

  ```python
  [<map expression> for <name> in <sequence expression> if <filter expression>]
  ```

  > `<map expression>`:对元素作用函数,表达式等
  >
  > `<name>`:可迭代对象;如果只是简单的重复内容,可以使用`_`
  >
  > `<sequence expression>`:范围,可以使用函数
  >
  > `<filter expression>`:条件,可以是函数,条件语句,布尔语句等

## 列表基本运算

- 1. 加法运算_列表拼接

  ```python
  list1+list2
  ```

  ```python
  from operator import add
  add(list1,list2)
  ```

- 2. 乘法运算_列表重复运算

  ```python
  num*list1
  ```

  ```python
  from operator import mul
  mul(num,list1)
  ```

  

- c.in not in(成员运算)

- d.\[\](对列表的元素进行访问和修改|0~N-1|-N~-1)

- 5. 切片运算

  ```python
  list[<start>:<end>:<strike>]
  ```

  > `目的`:对列表进行**访问和修改**|复制**列表**|制作**逆转列表**
  >
  > `效果`:列表直接赋值的结果只是另一个变量对相同的内容关联c
  >
  > `默认情况`:start=0|end=N|strike=1
  >
  > `end`:并不会被包括
  >
  > 任何一个参数都可以为负数,理解方式:一维向量,向左为正,向右为负

- f.关系运算(== != <= >=)(一个个元素进行比较)

- g.解包运算

1. 普通模式:一个元组赋给对应个数的变量.当不等时,引发'valueerror'

2. 星号表达式:\*修饰的变量变成列表;\*表达式只能出现一次



## 列表操作 

- 0. 访问元素

     1. 多重赋值方法

     ```python
     a,b,...=列表
     ```

     > 通过`解包运算`,访问数组元素

     2. 元素选择运算符

     ```python
     列表[num]
     ```

     > 直接拿出列表中索引位置为x的元素

     3. 使用等效函数

     ```python
     from operator import getitem
     getitem(列表,num)
     ```

     > 等效于`方法2`

- 1. 添加元素

 I.列表.append('xx')方法——在列表尾追加'xx',无返回值

 II.列表.insert(n,'xxxx')方法——在列表\[n\]的位置插入'xxx'，无返回值

- 2. 删除元素

 I.列表.remove('xxx')-删除列表中第一个指定的元素，无返回值

 II.列表.pop(n)(底层字节码:`CALL_METHOD`和`POP_TOP`)-删除指定位置的元素,n=-1=N时可以省略,返回被删除的元素——让列表变得像栈

 III.列表.clear()-清除列表所有元素

 IV.del关键字(底层字节码:`DELETE_SUBSCR`) 列表\[n\]-删除指定位置的元素,性能更优，无返回值

 V.删除列表中所有指定元素: while xx in list:list.remove(xx)

- 3.  遍历列表

     ```python
     for i in range(len(<lsit>)):
         <list>[i]
     ```
     ```python
     while i<ken(<list>):
         <list>[i]
     ```
     ```python
     for <item> in <list_of_items>:
         <suite>
     ```
     
     > 本方式中i会取到列表list_of_items中的值

- c.搜索位置

 I. 列表.index('xxxx',n)-从列表\[n\]开始检索第一个'xxxx'的索引,若n=0,省略

- d.频次检测

 I.列表.count('xxx')-统计出现的次数

- e.排序

 I.列表.sort(key=none,reverse=False)——按照ASCII进行列表排序;默认是按照从小到大排序;reverse=True,从大到小进行排序;key=len,按照字符串长度排序;key接受函数——永久排序

 II.sorted(iterable, *, key=None, reverse=False)——暂时排序,列表本身未发生任何变化

- f.反转

 I.列表.reverse()——反转数组的排序——永久修改但可复原

- g.获取列表长度

 ```python
 len(列表)
 ```

 III. sum(序列)函数:对一个序列中的项从左到右进行求和运算

## 嵌套列表(多维列表)
`定义`:任何值都可以包含再一个列表中,包含另一个列表

- 遍历列表

```python
for <x,y...> in <list>:
    <suite>
```

> `要求`:<x,y...>的内容必须和<list>的子列表的元素数量一致,其中各个子列表的数量必须一致
