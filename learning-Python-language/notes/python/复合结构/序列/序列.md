# 序列

## 基本特性

- **长度（Length）**：序列的长度是有限的，空序列的长度为 0。
- **元素选择（Element selection）**：序列中的每个元素都对应一个小于序列长度的非负整数作为其索引，第一个元素的索引从 0 开始。

## 拓展特性

- **成员资格(Membership)**:可用于测试某个值在序列中的成员资格
- **切片（Slicing）**：一个切片是原始序列的任意一段连续范围，由一对整数指定

## 特点

- 序列是可迭代值

## 序列操作

- 1. 许多序列操作可以通过对序列中的每个元素使用一个固定表达式进行计算，并将结果值保存在结果序列中
- 2. 选取原序列中满足某些条件的值
- 3. 聚合(Aggregation):将序列中所有值具合为一个值.例如:`sum` `min` `max`
- 4. `高阶函数`: 将`函数`应用到`推导表达式`的`元素求值`,`元素条件`,`聚合`(使用`双参数的reduce函数`)
