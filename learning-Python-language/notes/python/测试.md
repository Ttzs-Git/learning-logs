### 单元测试(Unit Test)

- **测试**也可用作**文档**：去演示如何调用函数，以及如何选择合适的参数值

- 测试需要选择**特定参数值**，并使用它们验证函数调用

- **有效测试**的关键是在实现新功能后**立即编写（并运行）测试**。在实现之前编写一些测试也是一种很好的做法，以便在你的脑海中有一些示例输入和输出

#### 断言(assertions:假值时，`assert` 会导致错误，使程序停止执行)

  ```python
  assert func(arg)==num,"解释"
  ```

#### 测试函数

```python
def func_test():
    assert func(arg)==num
    ...
```

> 测试多个数据

> **注意:**测试函数通常是在同一个文件或带有后缀_test.py的相邻文件中编写的

 #### 文档测试(Doctests)

```python
def func():
    """
    
    >>> func()
    num1
    >>>func()
    num2
    """
    func body
```

```python
from doctest import testmod
testmod()
```

> 使用此模块进行验证

```python
>>> from doctest import run_docstring_examples
>>> run_docstring_examples(func, globals(), True)
```

> `run_docstring_examples`:第一个参数是要测试的函数；第二个参数应该始终是表达式 `globals()` 的结果，这是一个用于返回全局环境的内置函数；第三个参数 `True` 表示我们想要“详细”输出：所有测试运行的目录

```bash
python -m doctest <python_source_file>
```

> 启动Python文件内的所有doctest

```sh
python -m doctest <python_source_file> -v
```

> 命令行工具有一个代表详细(verbose)-v的选项
