# 抽象

- 赋值(assignment):将名称和一个值或者函数进行绑定，保留值或者函数逻辑
- 导入:import 语句-将一个built-in的函数或者变量和进行绑定
- 定义:def 语句-与变量保持实时更新

> 对于抽象的理解:
>
> 1. 忽略细节,关注整体行为
> 2. 细节的不唯一,具有多样化的特点

## 数据抽象

 `定义`:将`数据表示`与`数据处理`的程序隔离的通用技术

 `目的`:形成复杂的`复合数据`

 `程序设计策略`:设置`假设`,再实现`行为`,最后完善`假设`

`基本思想`:确定一组`基本操作`,利用这些操作表达对某种值的所有操作,然后进使用这些操作来操作数据

`实现方式`:通过`选择器`和`构造器`的集合以及一些行为条件来表达抽象数据

## 函数抽象

`定义`:可以创建一个抽象来将函数的`使用方式`与`实现细节`分离

## 抽象屏障

`功能实现`:由更高层次调用,并使用较低层次的抽象实现

`作用`:增加代码的`健壮性`,减少高级函数对底层的依赖

## 元素

### first-class status

1. 可以与名称绑定
2. 可以作为参数传递给函数
3. 可以作为函数的结果返回
4. 可以包含在数据结构中
