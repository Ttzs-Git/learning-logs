## 编程要素

- 语言不仅是手段，更是一种能组织计算过程思想的框架
- 强大语言的机制:
  - **原始表达式和语句**：语言所关心的最简单的个体-->数字和算术运算
  - **组合方法**：由简单元素组合构建复合元素-->嵌套函数
  - **抽象方法**：命名复合元素，并将其作为单元进行操作-->将名称和值绑定

- 编程中，我们处理的元素:数据和函数（之后你会发现它们实际上并不是泾渭分明的）

> 思考:
>
> 前提:站计算机的视角理解这个问题；
>
> 第一，对于计算机而言，数据和函数都是01，这是统一的 
>
> 第二，在此前提下，如果认为数据是被处理的元素，函数是处理的方法，作为区别的角度。这是无法分明的。函数一样可以作为数据传入函数中，成为一种被处理的对象
>
> 函数有的时候像实时变化的量,变量像只记录字面值的可更改的量

- 表达式:数学表达式(中缀表示法),调用表达式(调用函数),调用库函数

> **中缀表示法**是一个通用的算术或逻辑公式表示方法， 操作符是以中缀形式处于操作数的中间（例：3 + 4），中缀表达式是人们常用的算术表示方法。
> 与**前缀表达式**（例：+ 3 4）或**后缀表达式**（例：3 4 +）相比，中缀表达式不容易被计算机解析，但仍被许多程序语言使用，因为它符合人们的普遍用法。
> 与前缀或后缀记法不同的是，中缀记法中括号是必需的。计算过程中必须用括号将操作符和对应的操作数括起来，用于指示运算的次序

- 绑定(一个值被赋予了名称，即名称绑定到了值上面):`赋值`，`import`(语句将名称与内置函数绑定)。`def`( 语句将名称与用户自定义的函数绑定)

> 绑定的对象:数据,函数
>
> 多重赋值:先求值，再赋值

- 求值程序本质上是递归的
- 环境:编译器可以用来记录名称,值,绑定的某种内存
