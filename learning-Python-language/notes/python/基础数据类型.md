## 总纲

## 原始数据类型

- 属性：

  1. 有一些可以求解为原始数据类型的表达式，被称为字面量（literals）。

  2. 有用于操作原始类型值的内置函数和操作符。

### 整形(int)

> `行为`: **整形字面值**自动转化为int,**数学运算符**可以操作这种值
>
> `属性`: 
>
> 1. **精确表示**整数,没有任何近似处理或大小限制
> 2. int是**无界**的,可以存储任意大小的数字

1. 进制:十进制(nnn);八进制(0onnn);二进制(0bnnn);十六进制(0xnnn)

2. 大数的下划线分组:3个为一组,输出不显示
